# AI-ассистент мастера маникюра 

## 🎯 Задача
Мастер маникюра  ведёт записи клиентов вручную в Google Sheets. Нужен ассистент, который:
1. Принимает записи клиентов через Telegram (текст или голос).
2. Показывает свободные окна и текущее расписание.
3. Отменяет и переносит записи.
4. Автоматически напоминает о завтрашних клиентах и присылает шаблоны для связи.

## 💡 Решение
Два связанных workflow в n8n:

### 1. AI Agent (диалоговый)
- **Вход:** сообщение в Telegram (текст или голос).
- **Голос:** транскрибация через OpenAI Whisper (Polza AI).
- **Память:** Window Buffer Memory (помнит контекст диалога).
- **AI Agent:** понимает намерение (создать/обновить/отменить/список) и возвращает **строгий JSON** с actions.
- **Логика:** n8n парсит JSON, разветвляет действия (Switch) и работает с Google Sheets.
- **Выход:** ответ в Telegram + обновление таблицы.

### 2. Напоминания (планировщик)
- **Триггер:** ежедневно в 15:00 МСК (17:00 по Уфе).
- **Логика:** находит записи на "завтра" по часовому поясу Уфе.
- **Формат:** формирует список клиентов + **готовые шаблоны сообщений** для каждого.
- **Выход:** отправляет сводку Эвелине в Telegram.

## 🔧 Стек
- **n8n:** оркестрация, Code nodes, Switch, Merge.
- **Polza AI:** gpt-4o-mini (чат), Whisper (голос).
- **Google Sheets:** база записей (Nails Bookings).
- **Telegram Bot API:** интерфейс для мастера.

## 📊 Особенности реализации
- **Строгий JSON-формат ответа** от агента (для надёжного парсинга).
- **Учёт часового пояса** (Уфа = МСК+2).
- **Защита от дублей** (UUID для записей).
- **Обработка ошибок** (Error handler для каждой ветки).
- **Шаблоны напоминаний** для клиентов (с адресом и оплатой).

## 📁 Файлы
- `agent-workflow.json` — workflow диалогового агента.
- `reminders-workflow.json` — workflow напоминаний.

## ⚠️ Настройка перед запуском
1. Замени `YOUR_POLZA_API_KEY` на свой ключ.
2. Замени `YOUR_TELEGRAM_CHAT_ID` на ID Эвелины.
3. Подключи свой Google Sheets аккаунт.
4. Настрой Telegram Bot Token в Credentials.
