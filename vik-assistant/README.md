# AI-ассистент инженера ВИК (Визуальный и измерительный контроль)

## 🎯 Задача
Инженеру по визуальному и измерительному контролю (ВИК) нужно быстро находить ответы в сложных нормативных документах (ГОСТы, МУ, регламенты), а также расшифровывать фото дефектов и голосовые сообщения прямо с производства.

## 💡 Решение
Мультимодальный AI-ассистент в Telegram на базе n8n:
1. **Текст:** Инженер задаёт вопрос, агент ищет ответ в базе знаний (Qdrant) и отвечает со ссылкой на пункт документа.
2. **Фото:** Инженер отправляет фото дефекта. Агент распознаёт его через Vision-модель (OpenAI gpt-4o-mini), описывает видимое и ищет норматив.
3. **Голос:** Инженер надиктовывает вопрос. Агент транскрибирует его (Whisper) и отвечает по тексту.

## 🔧 Стек и архитектура
- **n8n:** оркестрация workflow.
- **Polza AI (OpenAI API):** LLM (gpt-4o-mini), Vision, Whisper, Embeddings (text-embedding-3-small).
- **Qdrant:** векторная база для RAG (поиск по нормативному документу МУ.01.12 ред. 4).
- **Telegram Bot API:** интерфейс для инженера.

## 📊 Особенности реализации
- **Строгий RAG:** промпт запрещает модели выдумывать нормативы. Если в базе нет ответа, агент честно говорит об этом и просит уточнить.
- **Разделение факта и оценки:** агент различает, что видно на фото, а что является нормативным требованием из документа.
- **Ограничение доступа:** бот отвечает только авторизованному Chat ID (white-list).
- **Обработка ошибок:** ветки для неподдерживаемых форматов, таймаутов и сбоев API с просьбой повторить запрос.
