# AI-ассистент руководителя благотворительного фонда (Umar Fund Assistant)

## 🎯 Задача
Руководитель благотворительного фонда ведет учет доходов, расходов и задач в Google Таблицах. Ему нужен был голосовой и текстовый ассистент в Telegram, который понимает естественный язык, строго соблюдает исламский tone-of-voice (дуа, приветствия) и умеет не только отвечать, но и **совершать действия** (создавать, обновлять записи).

## 💡 Решение
Создан мультимодальный ИИ-агент в n8n, который:
1. **Принимает текст и голос** (транскрибация через Whisper).
2. **Анализирует запрос** и возвращает строгий JSON с командами.
3. **Управляет Google Sheets:** создает новые записи, обновляет статусы, ищет задачи по фильтрам.
4. **Отвечает с учетом контекста:** если Умар пишет голосовое, агент может ответить голосом (TTS).
5. **Соблюдает стиль:** добавляет «Ассаляму алейкум», дуа и эмодзи, как настоящий мусульманский секретарь.

## 🔧 Стек
- **n8n:** оркестрация (Switch, Merge, Code nodes, AI Agent).
- **Polza AI:** GPT-4o-mini (LLM), Whisper (транскрибация), TTS (синтез речи).
- **Google Sheets:** база данных (доходы, расходы, задачи).
- **Telegram Bot API:** интерфейс для руководителя.

## 📊 Особенности реализации
- **JSON-парсинг с защитой:** агент всегда возвращает валидный JSON, даже если LLM ошиблась (fallback).
- **Учет часового пояса (UTC+5, Екатеринбург):** все даты и фильтры (на завтра, на неделю) считаются корректно.
- **Умный маппинг задач:** если агент не знает ID, он ищет задачу по описанию.
- **Двойные напоминания:** ежедневный дайджест утром (что на завтра?) и еженедельный отчет (итоги недели, баланс фонда).
- **Безопасность:** доступ к боту только у доверенных Telegram ID.

## 📁 Файлы

- `reminders.json` — workflow ежедневных и еженедельных напоминаний.
