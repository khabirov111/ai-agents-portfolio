# Недельный дайджест с рейтингом администраторов

## 🎯 Задача
Формировать недельные отчёты и считать рейтинг администраторов по продажам товаров.

## 💡 Решение
AI-агент в n8n автоматически:
1. Получает недельный Excel-отчёт от Langame в Telegram.
2. Парсит данные через Extract from File.
3. Считает итоги недели (выручка, чеки, загрузка, товары).
4. Формирует ТОП-5 администраторов по продажам.
5. Отправляет дайджест в Telegram.

## 🔧 Стек
- n8n
- DeepSeek Chat Model
- Telegram Bot API
- Extract from File (XLSX)
- Google Sheets (история недель)

## 📊 Результат
- Полная картина недели в одном сообщении.
- Автоматический рейтинг администраторов.
- Сравнение с прошлой неделей.

## 📁 Файлы
- `workflow.json` — экспорт workflow.
- `prompt.md` — системный промпт.
